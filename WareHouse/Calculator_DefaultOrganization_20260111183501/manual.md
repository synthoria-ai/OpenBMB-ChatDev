# Calculator App User Manual

## Introduction

Welcome to the Simple Calculator App user manual. This application allows you to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. The app has a user-friendly interface that enables you to input numbers and operators easily.

## Main Functions

1. **Input Numbers**: Use the number buttons (0-9) to input numerical values.
2. **Arithmetic Operations**: Use the operator buttons (+, -, *, /) to perform addition, subtraction, multiplication, and division.
3. **Equals Button**: Press the equals button (=) to calculate the result of the operation.
4. **Clear Button**: Press the clear button (C) to clear the display.

## Installation

To run the Simple Calculator App, you need to have Python installed on your system. You can install the required dependencies by running the following command in your terminal:

```bash
pip install -r requirements.txt
```

## How to Use

1. **Run the Application**:
   - Open a terminal window.
   - Navigate to the directory where the `main.py` file is located.
   - Run the following command:
     ```bash
     python main.py
     ```

2. **Perform Calculations**:
   - Input the first number using the number buttons.
   - Select an arithmetic operator (+, -, *, /) to perform the operation.
   - Input the second number.
   - Press the equals button to see the result.

3. **Clear Display**:
   - To clear the display, press the clear button (C).

4. **Exit the Application**:
   - You can close the application window to exit the Simple Calculator App.
