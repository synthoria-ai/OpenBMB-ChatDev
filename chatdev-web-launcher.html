🚀 ChatDev Launcher

AI-Powered Multi-Agent Software Development

📍 Installation Location

/home/user/OpenBMB-ChatDev

🎯 Quick Start

Open a terminal and run:

cd /home/user/OpenBMB-ChatDev
./chatdev-launcher.sh "Your app description" "AppName"

💡 Example Commands

Create a Todo List App:

./chatdev-launcher.sh "Create a todo list app with add, delete, and mark as complete features" "TodoApp"

Create a Weather App:

./chatdev-launcher.sh "Create a weather app that shows current temperature and forecast" "WeatherApp"

Create a Game:

./chatdev-launcher.sh "Create a simple snake game with score tracking" "SnakeGame"

📂 View Your Created Apps

All apps are saved in: /home/user/OpenBMB-ChatDev/WareHouse/

🎮 Run the Calculator Example

To run the example calculator app (requires tkinter):

cd WareHouse/Calculator_DefaultOrganization_20260111183501
../../venv/bin/python main.py

🔧 Advanced Usage

  • Use GPT-4 instead: Add --model GPT_4
  • Custom config: Add --config YourConfig
  • Custom organization: Add --org YourOrg
